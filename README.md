
# 🛡️ SOC Analyst Journey

Իմ անձնական ուսումնական ուղին կիբերանվտանգության ոլորտում և SOC Analyst դառնալու ճանապարհին։

Այս պահոցում ներկայացված են իմ ուսումնական առաջընթացը, տեսական գիտելիքները, գործնական լաբորատոր աշխատանքները, անվտանգության միջադեպերի վերլուծությունները և թեստերի արդյունքները։

Իմ նպատակն է զարգացնել SOC Analyst-ի համար անհրաժեշտ գիտելիքներն ու գործնական հմտությունները։

---

## 🎯 Նպատակներ

- Զարգացնել SOC Analyst-ի գործնական հմտությունները։
- Սովորել անվտանգության մոնիթորինգ և սպառնալիքների հայտնաբերում։
- Ուսումնասիրել կասկածելի գործողությունների վերլուծությունը։
- Զարգացնել միջադեպերի հետաքննության և արձագանքման հմտությունները։
- Գործնականում աշխատել կիբերանվտանգության գործիքների հետ։
- Փաստագրել իմ ուսումնական առաջընթացն ու ձեռքբերումները։

---

## 🧠 Գիտելիքներ և տեխնոլոգիաներ

| Ոլորտ | Թեմաներ |
|---|---|
| SIEM | Անվտանգության տվյալների հավաքագրում և վերլուծություն |
| SOAR | Անվտանգության գործընթացների ավտոմատացում |
| EDR | Վերջնակետային սարքերի պաշտպանություն |
| Windows Security | Event Logs, Event IDs, PowerShell |
| Networking | TCP/IP, DNS, HTTP/HTTPS |
| Active Directory | Օգտատերեր, նույնականացում, թույլտվություններ |
| MITRE ATT&CK | Հարձակման մարտավարություններ և տեխնիկաներ |
| Incident Response | Հայտնաբերում, վերլուծություն, արձագանքում |

## 🔬 Գործնական հետաքննություններ

Ուսումնասիրվող թեմաների օրինակներ՝

- Failed Login Attempts — անհաջող մուտքի փորձեր։
- Suspicious PowerShell Activity — PowerShell-ի կասկածելի ակտիվություն։
- Brute Force Detection — գաղտնաբառերի ընտրության փորձերի հայտնաբերում։
- Suspicious Network Traffic — կասկածելի ցանցային տրաֆիկ։

Յուրաքանչյուր հետաքննություն ներառում է համապատասխան ապացույցներ, լոգեր, վերլուծություն և եզրակացություն։
