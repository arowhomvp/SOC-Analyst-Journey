
# Active Directory

Active Directory-ը Microsoft-ի ծառայություն է, որն օգտագործվում է կազմակերպության ցանցում օգտատերերին, համակարգիչներին և թույլտվություններին կառավարելու համար։

Օրինակ՝ կազմակերպության ադմինիստրատորը կարող է ստեղծել օգտատերեր, ավելացնել նրանց խմբերում և սահմանել հասանելիության իրավունքները։

SOC Analyst-ի համար կարևոր է հետևել կասկածելի փոփոխություններին։

Օրինակ՝ եթե սովորական օգտատերը հանկարծ ավելացվում է Administrators խմբում, դա կարող է պահանջել լրացուցիչ ուսումնասիրություն։

**Ինչ հասկացա**
- Կառավարում է օգտատերերին։
- Կառավարում է խմբերն ու թույլտվությունները։
- Օգնում է վերահսկել կազմակերպության հաշիվները։
- Կարևոր է անվտանգության հետաքննությունների համար։
