
# Windows Logs

Windows-ը պահպանում է համակարգում կատարվող տարբեր գործողությունների մասին տեղեկությունները։ Դրանք կոչվում են Event Logs։

Դրանց միջոցով հնարավոր է ուսումնասիրել օգտատերերի մուտքերը, ծրագրերի գործարկումը և համակարգային իրադարձությունները։

Օրինակ՝

- Event ID 4624 — հաջողված մուտք։
- Event ID 4625 — անհաջող մուտք։
- Event ID 4688 — նոր գործընթացի ստեղծում։
- Event ID 4672 — հատուկ արտոնությունների տրամադրում նոր մուտքի սեսիային։

SOC Analyst-ը կարող է օգտագործել այս տվյալները՝ հասկանալու համար, թե ինչ է կատարվել համակարգում։

**Ինչ հասկացա**

Windows Logs-ը կարևոր աղբյուր է համակարգում կատարված գործողությունները հետաքննելու համար։
