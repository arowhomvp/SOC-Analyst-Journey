
# Networking

Ցանցային գիտելիքները կարևոր են կիբերանվտանգության ոլորտում, քանի որ համակարգիչները և սերվերները մշտապես փոխանակում են տվյալներ։

Հիմնական հասկացությունները՝

- IP — սարքի ցանցային հասցեն։
- DNS — դոմենային անունը վերածում է IP հասցեի։
- TCP — ապահովում է տվյալների հուսալի փոխանցում։
- UDP — փոխանցում է տվյալները առանց նույն տեսակի հաստատման և վերաուղարկման մեխանիզմի։
- Port — օգնում է տարբերակել սարքի վրա աշխատող ցանցային ծառայությունները։
- HTTP/HTTPS — վեբ հաղորդակցության արձանագրություններ։

**Ինչ հասկացա**

Ցանցային գիտելիքները օգնում են հասկանալ, թե ինչպես են սարքերը հաղորդակցվում և ինչպես հայտնաբերել կասկածելի ցանցային ակտիվությունը։
